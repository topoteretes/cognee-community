# cognee-community-connector-snowflake

A Snowflake data-source connector for [cognee](https://github.com/topoteretes/cognee):
sync selected tables, query results and object comments into memory.

> **Work in progress.** Tracking issue:
> [topoteretes/cognee#4771](https://github.com/topoteretes/cognee/issues/4771).
> Setup steps (including key-pair auth), usage and a runnable example will land here as
> the connector is built.
