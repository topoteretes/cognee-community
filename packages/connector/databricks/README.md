# cognee-community-connector-databricks

A Databricks data-source connector for [cognee](https://github.com/topoteretes/cognee):
sync notebooks, Unity Catalog table metadata and their lineage into memory.

> **Work in progress.** Tracking issue:
> [topoteretes/cognee#4772](https://github.com/topoteretes/cognee/issues/4772).
> Setup steps (including the personal access token), usage and a runnable example will
> land here as the connector is built.
