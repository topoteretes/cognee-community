# AniList Connector for Cognee

Sync your AniList anime list (public GraphQL, no auth) into Cognee memory.

Setup: set ANILIST_USERNAME (your AniList username). No API key needed.
Install: uv pip install -e ./packages/connector/anilist  (from repo root /home/one-piece/cognee2/cognee-community)
Run: python packages/connector/anilist/examples/example.py
